# Redemptio support website

Public support, privacy, choices/deletion, license information, credits, and accessibility pages for Redemptio. English and Brazilian Portuguese.

Published at https://sandlerrodrigo.github.io/redemptio-support/

No analytics scripts, external fonts, cookies, or web forms are added. Edit the static HTML and CSS, commit, and push to main to update GitHub Pages.

App source code and private App Store submission information are not included.
